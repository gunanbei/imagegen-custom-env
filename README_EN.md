# imagegen-custom-env

[中文](README.md) · [English](README_EN.md) · [日本語](README_JP.md)

An independently installable Codex skill that wraps the official `imagegen`
workflow with project-aware custom credentials and a managed Python runtime.

## Requirements

- Codex with the built-in `imagegen` skill installed.
- Python 3.8 or newer to launch the wrapper. The skill can provision its own
  Python 3.12 runtime for image generation dependencies.

## Install

Clone this repository directly into the Codex skills directory:

```bash
git clone <repository-url> "${CODEX_HOME:-$HOME/.codex}/skills/imagegen-custom-env"
```

Restart Codex after installation so the skill is discovered. To update an
existing installation:

```bash
git -C "${CODEX_HOME:-$HOME/.codex}/skills/imagegen-custom-env" pull --ff-only
```

If you keep the repository elsewhere, install it with a symbolic link instead:

```bash
ln -s /absolute/path/to/imagegen-custom-env \
  "${CODEX_HOME:-$HOME/.codex}/skills/imagegen-custom-env"
```

## Verify

```bash
python3 "${CODEX_HOME:-$HOME/.codex}/skills/imagegen-custom-env/scripts/imagegen_custom_env.py" doctor
```

For generation, `run` selects the dedicated Python runtime and locates the
official `image_gen.py` itself. The first token after `--` must therefore be
`generate`, `edit`, or `generate-batch`; do not pass `python3` or an
`image_gen.py` path again.

The repository root is the skill root. `SKILL.md`, `agents/openai.yaml`, and
`scripts/imagegen_custom_env.py` are all required runtime files. Local secrets,
managed virtual environments, and generated bytecode are intentionally excluded
from version control.

## Versioning

Use semantic-version Git tags for releases, for example:

```bash
git tag -a v1.0.0 -m "imagegen-custom-env v1.0.0"
git push origin main --tags
```
